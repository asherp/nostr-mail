## Guidelines

- **Format:** PNG, keep the filenames above.
- **Capture:** light mode for consistency (the docs theme defaults to light).
  Capture the full screen/view, not the whole OS window.
- **Privacy:** use a throwaway/test account — scrub real email addresses,
  `nsec` private keys, and personal contact data before committing.
- **Size:** aim for roughly 1200–1600 px wide; keep files reasonably small.
